# FRL-NMP-flight-computer
2-layer KiCad flight computer PCB integrating Arduino Nano, MPU6050 IMU, BMP280 altimeter, and dual-servo control with regulated 3.3V power and isolated servo power.

Designed a 2-layer KiCad PCB integrating an Arduino Nano, MPU6050 IMU, BMP280 altimeter, and dual-servo control; designed 3.3V power regulation, I²C pull-ups, decoupling, ground planes, isolated servo power, and signal routing; completed ERC/DRC verification and generated fabrication files, BOM, schematic, and 3D renders.
